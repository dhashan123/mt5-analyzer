Your EA is your property. Here is exactly what happens to it.

Most buyers are asked to upload source code to a stranger and hope. This page is the short version of the handling policy. If you want it in writing before you send anything, ask for the NDA — or send yours.

Where it goes

The file is stored on a dedicated machine, in an encrypted volume, under one account. It is not uploaded to a public repository, a shared drive, a file-converter site, or a third-party chat tool.

Who can open it

Me, and the automated batch runner on the same machine. No contractor, no offshore team, no buyer, no “community” of reviewers.

How long it stays

Thirty days after the report is delivered, the source and every intermediate file are deleted. If you want it deleted sooner, say so and it is gone the same day. The finished report and the CSVs are yours; the source is not kept as a library.

What it is never used for

  • It is not resold, published, or reused in another client’s report.
  • It is not turned into a product, an indicator, or a template.
  • It is not used to train a model.
  • It is not shared with a broker, a prop firm, or a marketplace.

The NDA

A mutual NDA is available before you upload anything. Ask for it and I will send one to sign, or send yours. If your employer or prop firm requires a specific form, send it and I will read it before we start.

What I need

  • The .mq5 source, with any .mqh it needs — or the .ex5 if the source is not available.
  • The symbol, timeframe, date range, deposit and leverage you want. If you do not know, say “you choose” and I will state what I picked.
  • Any configuration that matters: spread mode, commission, swap, or a specific broker’s data.

What you get back

The report, the CSVs behind it, the raw terminal report, and the exact commands to reproduce every run. The source is not returned modified. If the EA does not compile, I tell you before spending the run time.

One honest limitation. A validation run needs the EA to compile in a real MT5 terminal. If it depends on a proprietary include file, a DLL, or a broker-only feed, say so up front — that is a scoping conversation, not something to discover after payment.
